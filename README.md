# RTL Protocol Engines

A collection of small SystemVerilog projects focused on implementing and understanding digital communication protocols using RTL and FSM-based design.

## Goals

* Build strong FSM and RTL design intuition.
* Understand protocol timing and handshaking.
* Design synthesizable SystemVerilog modules.
* Develop self-checking testbenches and verification skills.

## Protocols

Projects will be added progressively, starting with simpler protocols and moving toward more complex bus interfaces.

* UART
* SPI
* I²C
* APB
* AXI-Stream

Each project will include the RTL design, testbench, and relevant timing/state diagrams.

## Tools

* SystemVerilog
* Vivado / Icarus Verilog
* GTKWave

This repository is primarily a learning and experimentation project.
